# reference/

`cosmos-prototype.html` is the original single-file Kernel Cosmos prototype
(three.js r128 from cdnjs, one IIFE, about 1,600 lines). It is the behaviour
reference for the port in `src/projects/cosmos/`.

It is not part of the build. To view it, serve this folder and open the file
in a browser, for example:

```bash
npx vite reference --port 5180
# then open http://localhost:5180/cosmos-prototype.html
```
